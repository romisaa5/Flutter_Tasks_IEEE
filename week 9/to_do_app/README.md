# 📝 Flutter To-Do App

A simple Flutter app for managing tasks using SQLite (Sqflite).  
Users can add tasks with an optional due date using a customized DatePicker.

## 📦 Features

- Add and delete tasks
- Store tasks locally using Sqflite
- Custom DatePicker 
- Modern UI

## 🚀 Getting Started

### Prerequisites

- Flutter SDK
- Dart
- Android Studio or VS Code

### Run the App

```bash
git clone https://github.com/romisaa5/Flutter_Tasks_IEEE/tree/main/Week%209%20SQLite%20part(1)/to_do_app.git
cd flutter-todo-app
flutter pub get
flutter run
