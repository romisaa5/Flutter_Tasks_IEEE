### **Task 1**
- Prepared a **presentation** summarizing the content and explaining the **4 OOP principles**:
  1. **Abstraction** – Hiding implementation details and showing only the essential features.
  2. **Polymorphism** – The ability of different classes to be treated as instances of the same superclass, typically via method overriding or overloading.
  3. **Inheritance** – Allowing a class to acquire the properties and methods of another class.
  4. **Encapsulation** – Restricting direct access to some components and bundling data with methods that operate on it.
