## 🧠 **Objective**
Build a **local database system** using SQLite for an expense tracking app (**Expenzo**) that allows **Create, Read, Update, Delete (CRUD)** operations with persistent storage.

---

## 🖥️ **What You’ll Build**
### 1. **Home Screen**
- Displays all recorded expenses.
- Shows **title**, **amount**, **date**, and **category** for each record.

### 2. **Add Expense Screen**
- Input form fields:
  - **Title**
  - **Amount**
  - **Date**
  - **Category**
- Saves new expense to the SQLite database.

### 3. **Edit/Delete Functionality**
- Edit existing expense entries.
- Delete selected expense entries.

### 4. **Persistent Storage**
- Data remains available even after restarting the app.

---

## ✅ **Deliverables**
- Flutter app named **Expenzo** with:
  - SQLite local database setup.
  - Fully functional CRUD operations.
  - UI linked to database logic.
