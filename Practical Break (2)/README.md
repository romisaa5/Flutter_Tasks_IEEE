## 📝 **Task 01 – Flutter UI Implementation**
**Objective:**  
Create a product details screen in Flutter with custom styling.

**Requirements:**
1. **Fonts:**
   - Use **Audiowide** font from [Google Fonts](https://fonts.google.com).
2. **Product Image:**
   - Use [Belgium T-shirt image](https://socceruniformkits.com/wp-content/uploads/2022/03/belgium-home-shirt-2019-21-with-de-bruyne-7-printing_ss4_p-12042321u-ois4j8otb6nm1imu83dcv-0a936cd87a18451aa4cf1844950e5d01.jpg).
3. **Rating Bar:**
   - Use [`rate`](https://pub.dev/packages/rate) package.
   - Initial value: **4**.
   - Color: **Red**.
4. **Layout:**
   - Product image at top.
   - Product title and description.
   - Price and “Add to Cart” button.

---

## 🛠 **Flutter Concepts Applied**
- `List.generate()` for dynamic widget creation.
- `SingleChildScrollView` / `ListView` for scrollable UI.
- Using external packages for enhanced UI (rating bar).
- Applying custom fonts via `pubspec.yaml`.
- Network image loading and asset styling.
