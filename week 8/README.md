## 🎯 **Challenge – Git Basics**
Before starting work, researched the **most important Git commands**:
- `git init` – Initialize repository.
- `git clone` – Clone an existing repo.
- `git add` – Stage changes for commit.
- `git commit` – Save changes to history.
- `git push` – Upload commits to remote.
- `git pull` – Fetch and merge latest changes.
